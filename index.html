Contador Inteligente

Projeto desenvolvido em VisuAlg para praticar lógica de programação.

Neste projeto desenvolvi um contador utilizando conceitos de lógica de programação, estruturas de repetição e condições.

Código em VisuAlg 
algoritmo "Contador Inteligente"

Var
menu, N, L : INTEIRO

Inicio
N <- 1
repita
escreval("------------menu----------")
escreval("1 - progressiva")
escreval("2 - regressiva")
escreval("3 - encerrar")
leia(menu)
limpatela

  Se (menu = 1) entao
     escreval("qual numero deseja fazer a contagem progressiva?")
     leia(L)

     repita
        escreval(N)
        N <- N + 1
     ate (N > L)

  Fimse

  Se (menu = 2) entao
     escreval("qual numero deseja fazer a contagem regressiva?")
     leia(L)

     N <- L

     repita
        escreval(N)
        N <- N - 1
     ate (N < 1)

  FimSe

ate (menu = 3)

Cadastro Inteligente

Projeto desenvolvido em VisuAlg para praticar entrada de dados, condições e lógica de programação.

Neste projeto desenvolvi um sistema de cadastro utilizando informações fornecidas pelo usuário e estruturas condicionais para processar os dados.

Código em VisuAlg 
algoritmo "Cadastro Inteligente"

Var
menu, genero, cabelo, id, ContH, ContM: inteiro

Inicio

contH <- 0
ContM <- 0

repita

  escreval("=====MENU DE CADASTRO=========")
  escreval("-------faça-o-cadastro--------")
  escreval("1 - homem")
  escreval("2 - mulher")
  escreval("3 - encerrar cadastro")

  leia(menu)
  limpatela

  Se (menu = 1) entao
     genero <- 1
  FimSe

  Se (menu = 2) entao
     genero <- 2
  FimSe

  Se (menu = 1) ou (menu = 2) entao

     escreval("qual a sua idade?")
     leia(id)

     escreval("---informe a cor do cabelo---")
     escreval("1 - preto")
     escreval("2 - loiro")
     escreval("3 - castanho")
     escreval("4 - ruivo")

     leia(cabelo)

  FimSE

  Se (genero = 1) e (id = 20) e (cabelo = 1) entao
     contH <- ContH + 1
  FimSe

  Se (genero = 2) e (id = 22) e (cabelo = 2) entao
     contM <- ContM + 1
  FimSe

ate (menu = 3)

escreval("A quantidade de homens é", contH)
escreval("A quantidade de mulheres é", contM)
